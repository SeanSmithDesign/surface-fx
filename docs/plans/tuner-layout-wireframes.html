D — Timeline / Motion (After Effects / Rive)

Time becomes first-class. Same layers + inspector, but a bottom track shows each layer's trigger and envelope. Because surface-fx motion is reactive — hover, pointer, arrival — the track is a trigger + envelope editor with a preview playhead, not a keyframe timeline.

F — Bottom Bar Only (no side panels — the curiosity)

Everything collapses into one bottom bar; the stage owns the whole screen. Dials live in a horizontal, scrolling tray. Honest read: it's clean and touch-friendly, but it hits a wall fast — drawn here with where it breaks called out.

Inspiration board — tools worth stealing from

Where each direction's DNA comes from, plus one wildcard we haven't drawn.

Tool What we borrow Shows up in
After Effects / Rive Layer stack + timeline; thinking in triggers & envelopes D
Figma / Spline Layers left · canvas center · inspector right A
Ableton (device rack) Horizontal chained modules + macro knobs F, done better
Tweakpane / dat.GUI Compact folder-based dial panel — folders = our accordions B, E, drawers

Blender / Origami (nodes) Layers as connected nodes — a graph, not a stack wildcard — undrawn

The node-graph wildcard (G) is a real fork if surface-fx ever composes effects that feed each other. Say the word and I'll draw it.
